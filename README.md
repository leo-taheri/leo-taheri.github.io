# Leo Taheri Portfolio

A static engineering portfolio designed for GitHub Pages.

## Files
- `index.html` — page structure and content
- `style.css` — complete visual design
- `script.js` — interactive hero animation and cursor effects

## Publish on GitHub Pages
1. Open your `leo-taheri.github.io` repository.
2. Upload these three files to the root of the repository.
3. Commit the changes.
4. Open `https://leo-taheri.github.io`.

## Important edits
Before using the site publicly:
- Replace `your-email@example.com`.
- Replace the placeholder LinkedIn link.
- Add your CV file and connect the “Download CV” button.
- Replace placeholder project text with your real projects.
- Replace the abstract CAD visuals with project photos or renders when ready.
